# 04 · 字幕与结构件

字幕、章节卡、顶部 HUD、底部进度条、水印**全在一个 .ass 里**，
由 `final_pass.final()` 和封面、电平、BGM **一次编码**烧进去（≈1 分钟）。

⛔ `chain.post` 里有一步 `subs.py blank`：把逐场景字幕图置空。
不置空的话 `build_video` 会先把整段字幕烧进 clip，成片就是**两层字幕**。

---

## 字幕：一条一行，按标点断句

样式（都是被用户反馈逼出来的）：

| 项 | 值 | 为什么 |
|---|---|---|
| 字体 | 楷体粗一点（`STKaiti`） | 比黑体有人味 |
| 字号 | **60** | 42 号在手机上看不清 |
| 单行最宽 | 1000 px（1920 画布）≈ 16 个字 | 永远只显示一行 |
| MarginV | 120 | 贴底会挡住画面里 3D 标签的下沿 |
| 底色 | 半透明深色 | 亮画面上也读得出 |
| 高亮 | `*词*` → 青色 | 一条里最多标一个 |

⛔ `fonts.sub_name` 是**字体内部名**不是文件名，写错了 libass 会静默换成默认字体。

### 断句规则（`cues_of`）

1. 先按 `，。！？；：、` 切成**标点单元**
2. 单元本身超宽 → 切成几份**等长**的，切口尽量落在中间
3. 只有「两边都是完整句子」才允许并成一条，**被拆开的碎片一律单独成条**
4. 太短的尾条（≤4 字）并回前一条
5. 保险：任何一条都不许以标点开头

⛔ 用户原话：「断长句要断在中间，而且切剩的尾巴不许并进下一句」。
老写法是贪心填到满，剩「0 和 1。」两三个字跑去跟下一句挤，字幕就会**以标点开头**。

下刀位置三个限制：
- 标点不许当下一条的第一个字
- 不把 `1024` / `DDR5` / `99%` 劈开（LATIN 连续段）
- 不把「并排」「带宽」这种词劈开（jieba 词边界；没装 jieba 就只保证前两条）

### 时间：逐字定位，不按字数比例

有 align 就按**首末字的 whisper 时间**定每条的起止（`+0.12` 秒余量），
下一条的起点兜住上一条的终点。没有 align 才退回「按字数比例分」并打印一行警告。

## 四件结构件

长片没有这四件，观众不知道自己看到哪儿了。表在 `chapters.py`。

### ① 章节卡

章首 1.6 秒，大字 + `\fad(250,350)`，副标「第 N 章」。**第一章不弹**（片头刚过）。
章名 **≤6 字**，用画面词（「一口井」「叠成一栋楼」），别用「第三部分：技术原理」。

### ② 顶部 HUD

`章名  ›  小节名`，半透明，每段换一次。进章的第一段延后 1.8 秒出现，给章节卡让位。

### ③ 底部章节进度条（按秒推进）

⛔⛔ 旧写法是**整章一起高亮**——一章从头到尾都是同一个亮块，播到章中间完全看不出走了多远。
新写法：一条底带到底，上面压一条**按秒推进**的填充 + 一个游标，章名和分隔线照旧。

⛔ 为什么不用 `\t` 动画 `\clip`：libass 的动画裁剪要看版本，**静默失败**的话整条进度条
要么全亮要么不亮，而且渲完才看得见。改成**离散步进**，每秒一格，1920 px ÷ 总秒数 ≈ 1.8 px/格，
肉眼已经是连续的，零风险。

⛔ 每格只活它自己那一秒（`start=ta, end=tb`），不是「从 ta 活到片尾」——
后者会让片尾同时叠着上千个绘图。

### ④ 防搬运水印

每 30 秒从一个落点飘到另一个落点停住，下一段再飘回来。两个落点轮流坐庄，
**上一段停在哪儿、下一段就从哪儿起飞**，位置连续不闪现。

⛔ 两个落点都得避开已经有东西的地方，否则等于给自己的画面打码：
- 字幕居中、单行最宽 1000 px → 横向占 x 460~1460，所以水印 x 取 1556+
- 进度条在 y 1044~1080、HUD 在左上角 → 下落点 y 取 902
- 上落点 y 176，避开顶部章节卡（MarginV 300）

⛔ **半透明 + 描边两件都要**：只降不透明度，压到亮画面上就糊了；只描边，压到暗画面上又太跳。

`config.watermark` 留空就不打。

## ⛔ 章节表漏一段 = 最后一步 KeyError

`SEC[sid]` 直接炸，而且是卡在 `final_pass` 的最后一步——前面几十分钟的活白干。
`subs.py` 里有两道 assert 提前报：`SEC` 覆盖全部段、`CH` 里不出现 `SEC` 没有的段。

**改稿重排段落 / 拆段之后，章节表必须跟着改。**

## 封面

```
bl_cover.py  →  底图 PNG（Blender 渲，构图要给标题留左上角）
cover.py     →  加 HUD / 眉标 / 大标题 / 数据条  →  成品/<片名>_封面.png
final_pass   →  做成 1.5 秒缓推动画 + 0.35 秒淡入，xfade 0.3 秒接正片
```

- 正片音频整体后移封面时长（`adelay`），否则字幕音画错位
- BGM 从**封面第 1 帧**就垫进来，别让开头是死寂
- ⛔ 封面音效（whoosh）试过，用户反馈「怪」，去掉了；只垫 BGM
- 封面文案全在 `config.cover`：主标题**两行、每行 ≤6 字**，超了会撞到右边的建模
- 数据条三组数字，**最后一组用强调色**——反差就在它身上
