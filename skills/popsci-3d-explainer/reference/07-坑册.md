# 07 · 坑册

> 这条线上**所有会静默失败的地方**。都不报错，只是结果是错的；都真发生过。
> 按「出了什么怪事」查。

---

## 一、时间轴 / 拍点

**动画和口播错开，但一切正常**
`B.f("词")` 的词不在那块口播里 → **静默退回默认帧**。改稿时顺手动一个字就能打断一个拍点词
（真事：把「内存」顺手改成「内存条」，`B.f("内存的")` 就再也找不到了）。→ `check_beats_kw.py`

**某一镜画面停在旧拍点**
`chain.render` 默认「帧数够就跳过」。**段落变短时旧帧数反而更大**，整段被静默跳过。
判据必须是「帧数**恰好相等**」，不是 `>=`。

**`make.py beats` 报 `KeyError: 't'`**
改了稿却没先刷 storyboard：`align.py` 读的是 storyboard 里的**旧稿** → `align.json` 存的是旧稿 →
`_inject_t` 一比不一致，打印「align 过期」然后**整段跳过**，所有块都没有 `t`。
**改稿之后第一件事是 `make.py storyboard`。**

**改稿会连带换掉拍点锚词**
分镜块靠 `at`（口播里的一小段原文）定位。改稿时如果把锚词那句话改了，
块会退回「按上一块之后第一个字」定位，切点会偏。

**只改读音侧，字幕整段错位**
`{{长|涨}}`、`{{，|。}}` 这类改法**显示串一个字没动**，但 wav 变了。
align 的 stale 判据必须**同时**比：显示串、读音串、wav 时长。

**插过停顿不重对齐 → 整段偏几秒**
wav 变长了而文本一个字没动。拿「有停顿那一版」的时间轴去给「没停顿的音频」定落点必错。

## 二、配音

**某段一处停顿都没插过**
落点串对应的句子被改了、或者段被拆开了。`plan()` 只打印一行「找不到落点」，日志一长看不见。
→ 改完稿跑 `pauses.py plan` 逐行看。

**停顿处吞音**
按 align 字边界中点直接下刀，而 whisper 的字边界有 ±100 ms 误差 → **33/33 处全切在有声处**。
刀口要落在能量谷底、按目标间隙补足、**两侧都要淡**（只淡一侧的话，停顿之后那一刀是硬起，削掉下一个字的字头）。

**TTS 整段复读，而回读检查报 OK**
`check_read.py` 按拼音比但只报 ≤3 音节的 `replace`；几十音节的整段重复是一个 `insert`，它一条都不报。
→ 另跑 `check_dup.py`（≥8 音节的 insert/delete 都报）。
⛔ 两边都要先去掉中文数字字符，否则「百分之八十七」vs「87%」会刷一堆假警报。

**whisper 转写里同一句连出现 6 次**
`condition_on_previous_text` 默认 True，长音频上**解码循环**。音频本身是好的。
后果是 `check_dup` 拿这份转写当证据报假的「整段复读」，差点去切一段好音频。→ 关掉它。

**`tts_raw` 里的原始输出没了**
按 mtime 同步 `tts` → `tts_raw`。`pauses.apply()` 会就地改 `tts/`，
第二次跑 `audio()` 时「已插过停顿」的音频被当成原始素材抄了进去。
→ `tts_raw` **只在缺文件时建立，之后只读**。

**汉字转写英文 = 哑巴英语**
`四零七零踢` → 听成 "4070T"；`扣沃斯` → "扣卧师"。**直接写英文才对**（`4070 Ti` ✓）。
但也有反例：`CoWoS` 原样会读成 "Code WOS"，要写 `COWOS`；`DDR5` 会读成「滴滴阿瓦」，要写 `DDR 5`。

**本地 TTS 静默退出，只出了前 N 条**
进程不退、攥着 6~10 GB 显存，下一次补跑抢不到显存就**静默退出**，越补越死。
→ 每次配音后**数 wav 数 == 段数**；排查看 `nvidia-smi` 进程区的 `C` 类型行
（别用 `tasklist | grep python` 数——管道编码问题会返回 0，误判成「进程已退」）。

## 三、建模与渲染

**「光线很暗，建模照不全」**
自动曝光只量「比背景亮 0.06 的像素」——那个掩膜**只框到自发光**（发光缝、标签、亮台子），
靠灯照亮的机身进不了掩膜。→ 再量一次每个 MESH 各自画面框内的 p75，两个取小。

**曝光推到 ×42，整幅纯白**
上一条的修法用了「整体大框」，而画面是「一根斜放的长条 + 一颗小方块」，
整体框占了大半张画面、框里绝大多数是空的 → 量出来就是背景电平。
→ 改成 `_content_mask()`：每个 MESH 各自的框。

**标签灰扑扑压在画面上**
自动曝光是靠缩放「灯 + 所有发光材质」实现的，标签也是发光材质，被一起缩到 0.26 倍。
→ 标签是 UI，`_scale_emission(k, skip=_font_mats(sc))`。

**主体只占画面高一成半**
取景把**还没出场的物体**算进了外接框（吊在天上等着落位的、停在画外的）。→ `L.hide` 掉。
⛔ 但起手也不能全 hide：第一帧全黑会被空场检查报。

**字挂多高都被拉回来压在主体上**
取景按 MESH 框的**宽度**定，16:9 下竖向只覆盖「框宽 × 9/16」。
框 14 宽 × 7.3 高时竖向只有 8 个单位、主体自己占 7.3 —— **天上根本没有空当**。
→ 先算「框宽 × 9/16 − 主体高」，不够 2 个单位就别往天上挂；或者把布局摊宽。

**标签摞成一团 / 掉出画外**（六层病因，联络表上看不出来）
见 `03-建模与镜头.md` 的表。核心是：三道工序都往上推、相机先定死、按满尺寸量框、
取需求最大的那一帧换算。

**调半天画面纹丝不动**
改了相机朝向但没**当场打关键帧**。相机旋转是烤出来的曲线，下一轮 `frame_set` 会按曲线重新求值。

**镜头里给灯打的关键帧被抹掉**
`relight()` 会删掉所有灯重建。→ 用 `bs.opts(dim=(帧, 倍数, 过渡帧数))`。

**并排对比的镜头被转成了前后**
自动斜看。→ `bs.opts(oblique=False)`。

**整摞东西永远不落地**
`L.key_loc` 会**就地修改** `o.location`：先写「抬高 5」再拿 `tuple(o.location)` 当落点，
读到的已经是抬高后的值。→ **落点必须先存下来。**

**楼落了，缝留在半空**
`bs.stack()` 的返回值**只有芯片层**，层间发光缝和 base 不在里面。→ 按名字前缀收齐整摊。

**盒子被压成 1×1×1**
`L.box` 把 size 存进 `object.scale`，直接 `L.key_scale(o, f, (1,1,1))` 就是这个后果。→ 用 `bs.key_rel`。

**渲染 4 秒 FAIL 且没有 traceback**
多个 blender 进程抢同一个 `%TEMP%` 曝光探针 PNG。→ 临时文件名带 PID。

**盘满了但完成计数一直不涨**
blender 每帧报 `No space left on device`，看计数会以为只是渲得慢。
→ 开渲前 `C.assert_disk()`；monitor 除了盯计数再 grep 一条 `No space left`。

**补渲清单漏掉 28 镜**
遍历「已有的目录」找过期的 → 上一轮跑到一半被掐掉、帧已经搬走了，
**「没有目录 = 不在候选里」**。→ 判据改成：**把镜头清单当全集**，
目录不在 / done.txt 不在 / done.txt 太旧，三者任一都算要渲。

**量到的是上一部片的镜头**
`import bl_shots` 撞了同名文件，`sys.path` 顺序被改过好几道。→ `shotload.py` 按绝对路径加载。

**前面渲完的镜头停留在旧逻辑上**
在重渲途中改了生成器。→ **改完再开渲**。

## 四、音频与混音

**片尾十几秒死寂**
`amix` 的 `duration=first` = 第一路输入（人声），人声一停整条音轨就断。→ `longest`。
⛔ 这个坑**看代码推不出来**，只能 ffprobe 量音频流长度。

**片尾放的是开场曲**
BGM 混音总长 < 成片总长，`-stream_loop -1` 绕回了开头。**是巧合，不是设计。**

**成片真峰 +0.7 dBFS（已削顶）而 LUFS 看着正常**
峰值和响度是两个独立验收项。采样峰被 alimiter 挡住了，AAC 编码后的**峰间**真峰照样冲过 0。
→ 单独量 `ebur128=peak=true`，每提一档响度重量一次。

**混音 wav 真峰 −0.5 dBFS，成片却 +1.6 dBFS**
AAC **192k** 在爆破音 + 鼓点叠在一起的地方把真峰冲过 0。限幅压到 0.79 没用，换 `aac_coder=twoloop` 也没用；
码率提到 **256k** 就回到 −0.6。→ `final_pass.py` 已改成 256k。验收必须量**编码后的成片**，不是混音 wav。

**按短时电平找静音，越往后越找不到**
窗口步长写成 `int(sr*0.005)` 个采样，却按「5 ms 一格」换算回秒：44100×0.005 取整是 220 采样 = **4.9887 ms**，
一千秒的音频漂出 3 秒，刀口全部落在有声处。→ 秒数一律按 `hop_samples / sr` 回算，窗中心再补半个窗长。

**「有呜呜声」修了 BGM 还在**
两个来源：BGM 的次低频 + 人声自己的段落性隆隆。两道都要上。

**「还有嗡嗡声」而所有低频处理都没碰到它**
那是 **~299 Hz 的窄带稳态哨音**，不是低频隆隆。跟段落长度正相关，是 TTS 长段落上生出来的。
peaking EQ 打不死（残留峰会跑到 302~305）、`afftdn` 完全无效（把纯音当信号）。
→ 真陷波 `bandreject`，两个中心各两刀。

**「BGM 有些片段声音很小」**
曲子自己的弱段被原样带进来了（混音短时电平极差 25.8 dB）。→ `dynaudnorm` 慢速动态归一。
⛔ 别用 `acompressor`，峰值会顶到 1.000。

**两首曲子接缝处音乐消失**
史诗曲渐弱收尾 + 3 秒交叉正好落在两条尾巴中间。→ 进交叉前先剪掉头尾低于自身中位 6 dB 的部分。

**选曲打分判不出「这首中间一分钟没声」**
打分只听曲子正中间那 30 秒。→ `bgm.py prof` 量整首，看 lull / iqr / lvl。

## 五、字幕与总装

**成片有两层字幕**
`chain.post` 里漏了 `subs.py blank`，`build_video` 先把整段字幕烧进了 clip。

**字幕以标点开头**
断句贪心填到满，剩两三个字跑去跟下一句挤。→ 超宽单元切成**等长**几份，碎片一律单独成条。

**字幕字体变成了默认宋体**
`fonts.sub_name` 写的是文件名不是**字体内部名**。libass 静默换字体。

**libass 读不到中文路径的 ass**
→ ass 和字体先拷到 ASCII 临时目录（`subs.subs_filter()` 已经这么做）。

**concat 静默丢帧 / 报 SAR 不一致**
两条流规格不同。→ 字幕烧完和片尾都补一道 `format=yuv420p,setsar=1,fps=N`。

**xfade 把总时长缩掉了**
`(n−1)×T`，而字幕和拍点都按绝对秒排。→ 每段多取 T 秒素材再叠回去。

**`tpad` 冻帧补时长，一帧都没补上**
`select=...,setpts=N/FRAME_RATE/TB` 之后流的帧率是**未定义**的，`tpad=stop_mode=clone:stop=N` 静默什么都不做。
→ 先 `fps=30` 再 `tpad`。另外用 `select` 从长片里取一段时，**输入端要给 `-t`**，否则流不结束，tpad 等不到结尾也不生效。
补完用 ffprobe `-count_frames` 数帧，别信 filter 串写对了。

**`final_pass` 最后一步 KeyError**
章节表 `SEC` 漏了一段。→ `subs.py` 里两道 assert 提前报。

**进度条要么全亮要么不亮**
用 `\t` 动画 `\clip`，libass 版本相关、**静默失败**，而且渲完才看得见。→ 改成每秒一格的离散步进。

**片尾同时叠着上千个绘图**
进度条每格写成「从 ta 活到片尾」。→ 每格只活它自己那一秒。

**`_durs.json` 拿到旧时长**（症状：某段莫名其妙特别长）
它只由 `stage_tts` 生成，绕过 `--only tts` 之后改稿不会自动刷新。→ 从 `tts/*.wav` 重建。

**样片没有音轨**
带分辨率后缀的成片曾经就没有音轨，肉眼看不出。→ 切完 ffprobe 数流，<2 条就 assert。

## 六、验收

**验收全绿但验的是旧片**
「A 生成 B、下游只读 B」没加 mtime 闸门。**这条给过两轮假绿灯。**
→ 验收必须落在用户要打开的那个文件上，第一道闸就是 mtime。

**格子盖了假章**
`shot_files` 漏登一个镜头文件 → 改了那里的镜头、帧数没变，旧章还生效。

**qc 表把好镜头报成低对比**
`txtmin` 只采 85% 那一帧，逮到了正在弹出动画中途的标签。
**那张表是筛子不是判据**，排完序还要一镜一镜看图。

**联络表上什么都看不出来**
缩到 1/6 时标签细节全糊。→ 发现可疑就调 1080p 原图确认。

**把「一直就这样」当成「本轮弄坏的」**
→ 和回收站里的旧帧对照，只修真回归。（真发生过：五处压字里只有一处是本轮回归。）

## 七、工程纪律（Windows）

- ⛔ 中文路径的 ffmpeg 在 Git Bash 里会编码坏 → 用 PowerShell 跑
- ⛔ 不要用 `Get-Content | Set-Content` 回写中文文件（不可逆损坏），改文件走编辑器或 Python
- ⛔ 长任务必须**真 detached**（`Start-Process -WindowStyle Hidden`），判在不在跑看**产物 mtime**
- ⛔ 别用 `| tail` 判成败：管道退出码是 tail 的，会吞掉 python 报错误判「成功」
- ⛔ 废弃文件**只搬不删**，每批一个日期目录
