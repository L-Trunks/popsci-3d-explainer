# 00 · 配置与依赖

## 一句话

**除了 `config.json`，任何脚本里都不应该再出现绝对路径、片名、字体名、曲名。**
读取优先级：环境变量 `POPSCI_<KEY>` > 同目录 `config.json` > `config.py` 里的默认值。

跑 `python config.py` 会把当前解析结果打印一遍（含磁盘剩余空间），起手先跑这个。

---

## 必须装的

| 东西 | 干什么 | 装法 / 备注 |
|---|---|---|
| **Blender 4.5+** | 渲染。用 EEVEE Next，不用 Cycles | 只用命令行 `-b`，不开界面 |
| **ffmpeg / ffprobe** | 编码、切段、混音、量响度 | 必须在 PATH 里 |
| **Python 3.10+** | 除渲染外的全部 | 见下面的包 |

Python 包：

```
pip install numpy soundfile pillow jieba pypinyin
pip install edge-tts                 # 默认配音后端
pip install faster-whisper           # 逐字对齐（要 CUDA 才快；CPU 也能跑，慢）
pip install librosa                  # 只有 bgm.py scan/prof 要
pip install matplotlib               # 只有 chart.py 要
```

`jieba` 不装也能跑（字幕断句会退化成「只保证不劈开数字和字母」）。
`librosa` 不装就别用 `bgm.py scan`，直接在 `bgm.files` 里点名几首曲子。

**GPU**：12 GB 显存足够。渲染的瓶颈不是算力——实测 GPU 利用率 73% 但功耗只有 125W/310W，
卡在同步延迟上。所以多开进程比换卡有用：2 进程 1.60×、3 进程 1.81×（见 `run_par.py`）。

**磁盘**：一部 20 分钟的片，帧序列约 **32 GB**（1920×1080 PNG，一镜约 0.37 GB），
`work/` 整个目录约 31 GB，**每重渲一轮就多压 30 GB 废弃帧**。开渲前 `C.assert_disk()` 会挡。

## config.json 全字段

### 片子

| 字段 | 说明 |
|---|---|
| `title` | 片名。成品文件名 `成品/<title>_成片.mp4`、storyboard 的 outfile 都从这儿来 |
| `outdir` | 成品目录名，默认 `成品` |
| `script_md` | 反生成的稿文件名，默认 `稿.md` |
| `fps` / `canvas` | 默认 30 / [1920,1080] |
| `shot_files` | **镜头函数散在哪几个文件里**。⛔ 它是格子法指纹的一部分，漏登 = 盖假章 |
| `speech_rate` | 净语速（字/分），只用来估时长。短视频平台约 320、长视频平台约 375（我们的定档） |
| `terms` | 本片的阻塞性名词。`grid_script.py --lint` 会打印每个词**第一次出现在哪一段** |

### 机器

| 字段 | 说明 |
|---|---|
| `blender` | blender.exe 全路径。留空会去常见安装位置和 PATH 找 |
| `py_audio` | 装了 faster-whisper / soundfile / numpy 的解释器。留空 = 当前这个 |
| `py_build` | 跑 build_video.py 的解释器（PIL/numpy 即可），留空 = 同上 |
| `whisper_model` | `large-v3`（自动下载）或本地目录 |
| `whisper_device` | `cuda` / `cpu` |
| `trash` | 废弃产物的搬运目的地。**红线：只搬不删**——查回归时要拿旧帧和新帧对照 |
| `disk.drive` / `disk.min_gb` | 开渲前的空间闸门，默认 40 GB |

### 字体

| 字段 | 默认 | 用在哪 |
|---|---|---|
| `fonts.ui` | msyhbd.ttc | 3D 标签、卡片 |
| `fonts.ui_regular` | msyh.ttc | 卡片正文 |
| `fonts.mono` | consola.ttf | 终端视频、封面角标 |
| `fonts.sub_file` | STKAITI.TTF | 字幕文件路径 |
| `fonts.sub_name` | `STKaiti` | ⛔ **libass 按字体内部名匹配，不是文件名**。写错了字幕会静默换成默认字体 |
| `fonts.sub_size` | 60 | ⛔ 42 号在手机上看不清 |
| `fonts.display` | 空 | 封面大标题的展示字体，没有就退回 `fonts.ui` |

### 配音

```jsonc
"tts": {
  "backend": "edge",                    // 默认，免费
  "voice": "zh-CN-YunxiNeural",         // python -m edge_tts --list-voices 看全部
  "rate": "+8%",
  "tempo": 1.0                          // 出声之后再 atempo 变速
}
```

换成本地克隆：

```jsonc
"tts": {
  "backend": "voxcpm",
  "python": "path/to/envs/voxcpm/python.exe",
  "script": "path/to/tts_voxcpm.py",     // 就是本 skill 里那一份
  "model":  "path/to/VoxCPM2",
  "ref":    "path/to/参考音.wav",         // 同名 .txt 放文字稿 → Ultimate Cloning
  "tempo":  1.15                        // ⛔ 它只有 ~246 字/分，不变速片子会被拖长 34%
}
```

⛔ 参考音必须是**标准发音**：Ultimate Cloning 会照搬口音（平翘舌 shi→si 会被学走）。
⛔ 参考音自己的音色缺陷会带进每一段（实测胸腔比 +9.2 dB = 低频厚），
   这类问题**在最后一次混音里修**，别回头改素材层。

### 音频目标

| 字段 | 默认 | 说明 |
|---|---|---|
| `audio.seg_lufs` | −16.5 | 单段 wav 对齐到这个响度 |
| `audio.target_lufs` | −11.5 | 成片响度。−14 是 B 站归一化线，做到 −11.5 平台会压回去一点，但本地播放直接变响 |
| `audio.limit` | 0.88 | alimiter 上限。**真峰验收线 ≤ −0.3 dBFS**，每提一档响度都要重量一次 |
| `audio.bgm_v` | 0.34 | BGM 音量（也可用环境变量 `BGM_V` 临时试） |
| `audio.bgm_hp` | 100 | BGM 在成片混音里的二次高通 |
| `audio.notch` | [] | 稳态哨音陷波中心，如 `[299, 306]`。⛔ **量出来才填**，别照抄别人的频点 |

### BGM

```jsonc
"bgm": {
  "lib":  "",            // 曲库根目录；空着就只用 files
  "subs": [""],          // 曲库里要扫的子目录
  "files": [],           // 不用曲库时：直接写几首的绝对路径
  "pick": []             // 定版曲单（按出场顺序的文件名）；空 = 按打分自动取前 N 首
}
```

免费来源：YouTube Audio Library、Pixabay Music、Free Music Archive（CC0）；
incompetech（Kevin MacLeod）是 **CC-BY，片尾必须署名**。

### 其他

| 字段 | 说明 |
|---|---|
| `watermark` | 防搬运水印文字，空 = 不打 |
| `samples` | 样片清单，`{"name","head"}` / `{"name","seg"}` / `{"name","seg":"LAST"}` |
| `cover` | 封面文案：`slug` `sign` `ep` `badge` `title`(两行) `sub`(两行) `stats`(三组数字) |

## 跨平台

这套东西在 **Windows** 上跑通。移到 Linux/macOS 要改的地方：

- 字体路径（`fonts.*`）
- `config.py` 里 blender 的候选路径
- `subs.subs_filter()` 把 ass 和字体拷到 ASCII 临时目录，是为了绕开 **libass 吃不了中文路径**；
  Linux 下这一步无害，留着也行。
- `%TEMP%` → `tempfile.gettempdir()`（代码里已经是这个）

⛔ Windows 上还有两条：中文路径的 ffmpeg 在 Git Bash 里会编码坏（用 PowerShell 跑）；
   不要用 `Get-Content | Set-Content` 回写中文文件（不可逆损坏）。
